# Genesis Lab — Artificial Universe Simulator

Локальная лаборатория искусственной жизни: TypeScript, React, Vite, Canvas 2D, Web Worker и Vitest. Никаких API, аккаунтов или внешних серверов во время работы. Интерфейс на русском языке. Это экспериментальная модель эволюции, а не доказательство появления сознания.

## Запуск

Требуется Node.js 22+ и npm.

```sh
npm install
npm run dev
```

Откройте адрес, напечатанный Vite (обычно http://localhost:5173).

```sh
npm test          # 16 автоматических тестов
npm run build    # строгая проверка TypeScript и production-сборка
npm run preview  # просмотр production-сборки
```

`package-lock.json` фиксирует версии; для CI используйте `npm ci`. Зависимости нужны только при установке, работа приложения полностью локальная. Сборку `dist/` можно разместить на любом статическом хостинге; открытие через `file://` не поддерживается из-за ES modules / Worker.

## Управление

- Пауза, запуск, один шаг, скорость 0,5–10×. Один шаг доступен на паузе.
- Введите seed и нажмите кнопку рядом с ним: новый мир создаётся с текущими параметрами. Перезапуск делает то же самое.
- Параметры среды применяются на следующем вычислительном шаге, в том числе во время паузы. Начальная популяция действует при новом запуске. Каждое изменение записывается вместе с номером шага.
- Нажмите организм на карте, чтобы увидеть энергию, возраст, родителя и геном. Круг показывает радиус восприятия. Доступен также выбор из списка. Перетаскивание перемещает карту; кнопки меняют масштаб и центрируют её.
- «Сохранить» скачивает JSON обоих миров со всеми состояниями, историей, журналом действий и PRNG. «Восстановить» читает файл, проверяет его и ставит симуляцию на паузу. Неправильный файл не заменяет существующий мир. Максимальный размер — 16 МБ.
- «Воспроизвести эксперимент» заново рассчитывает оба мира от исходного seed с исходными параметрами и журналом изменений до их текущих шагов. Это проверка воспроизводимости, после которой можно продолжить наблюдение. Для нового запуска с тем же seed используйте перезапуск.
- Сравнение начинает A и B с шага 0 и одинаковым seed. Переключайте вкладки A/B для карты, инспектора и отдельных параметров. При запуске оба мира получают одинаковое количество шагов; два графика и таблица показывают различия. B по умолчанию имеет вдвое меньшее восстановление ресурсов. Завершение сравнения также перезапускает миры.

## Правила мира

### Пространство и питание

Тор 960 × 640: пересечение края переносит организм на противоположную сторону. Питание хранится в 60 × 40 ячейках размером 16 × 16. В начале каждая ячейка получает равномерно случайное количество от 0 до ёмкости. В начале каждого шага добавляется `regeneration × 0.1`, максимум — `capacity`. Уменьшение ёмкости обрезает запас на следующем шаге. Пища не перемещается, не возникает из умерших организмов и не имеет сезонности.

### Наследуемые признаки

| Ген | Диапазон | Следствие |
| --- | --- | --- |
| Скорость | 6–48 пикселей/с | Быстрое перемещение, квадратичная стоимость движения |
| Восприятие | 16–96 пикселей | Дальность локальных сигналов, дополнительный расход энергии |
| Метаболизм | 0,4–2 | Скорость поглощения пищи и стоимость существования |
| Агрессивность | 0–1 | Притяжение/отталкивание соседей, захват энергии и стоимость контакта |

У основателей все гены независимы и равномерны в своих диапазонах. Начальные координаты и направление случайны. Возраст равен 0, энергия равномерна в [35,65), поколение — 0.

### Локальный контроллер

Никаких заданных ролей, целей выживания, обучения, фитнес-функции или сценариев победы нет. Каждый организм складывает направленные сигналы от центров ресурсных ячеек внутри радиуса: `food / (1 + distance²)`. Соседи внутри радиуса дают сигнал `(aggression − 0.5) × 0.15 / (1 + distance)`. Ниже 0,5 это отталкивание, выше — притяжение. Расстояние учитывает замкнутые границы.

При суммарном сигнале больше 0,001 направление поворачивается на 30% кратчайшего угла к сигналу, плюс 20% шума блуждания. Иначе применяется только блуждание. Шум равномерен в [-0,25;0,25) радиан на шаг. Положение меняется на `speed × timestep` в выбранном направлении.

### Энергия, контакт и смерть

При расстоянии меньше 7 пикселей организм отнимает у соседа до `aggression × 3 × timestep` энергии, получает 60% захваченного и платит `aggression × timestep`. Взаимодействие может происходить в обе стороны; потери энергии не компенсируются.

После движения организм съедает до `5 × metabolism × timestep` питания из текущей ячейки. Затем платит:

```
(upkeep × metabolism + 0.0015 × speed² + 0.001 × sense) × timestep
```

Запас ограничен 150 единицами. Организм умирает при энергии ≤ 0 или возрасте выше `maxAge`. Смерть не восполняет питание. Вымерший мир остаётся пустым до перезапуска; ресурсы продолжают восстанавливаться.

### Размножение и мутации

При энергии > 100 и возрасте > 8 секунд возможно одно бесполое размножение за шаг. Родитель тратит 55 единиц, потомок получает 40, возраст 0, поколение родителя + 1, позицию на 8 пикселей правее с переносом через край. Направление и остальные координаты наследуются. Каждый ген независимо мутирует с вероятностью `mutation`; прибавка равномерна в ±12,5% полного диапазона гена, результат ограничен его диапазоном. Полезность мутации определяется дальнейшими взаимодействиями.

Популяция ограничена 1200 организмами: размножение прекращается на лимите. Это ограничение вычислительных ресурсов, а не биологическая закономерность.

### Порядок и детерминизм

Шаг фиксирован: 0,1 с. Seed хешируется FNV-1a (итерация по символам строки), случайные числа выдаёт Mulberry32. `Math.random`, часы и DOM в ядре отсутствуют. Организмы обновляются последовательно по стабильному порядку IDs: ранние организмы могут первыми съесть пищу или захватить энергию. Пространственные корзины строятся в начале шага; объекты внутри них изменяются по мере обновления. Это явный порядок модели, который может влиять на исход. Потомки вступают в симуляцию со следующего шага. После обновления удаляются погибшие и добавляются потомки.

Одинаковые seed, параметры и последовательность изменений на одинаковых шагах дают одинаковое состояние. Скорость отрисовки и размер пакета шагов на исход не влияют. Снапшот сохраняет текущее состояние PRNG и следующего ID, поэтому продолжение совпадает с непрерывным запуском. Точное побитовое совпадение предполагает ту же версию ядра и совместимый JS runtime; разные реализации тригонометрии могут давать небольшие расхождения между браузерными движками. Формат снапшота версионирован (v1).

### Статистика

Текущие значения рассчитываются по живым организмам. «Поколение» — максимум среди живых, поэтому может уменьшаться после гибели последнего представителя. Разнообразие — корень среднего квадрата отклонений всех четырёх генов от средних, нормализованных на полный диапазон каждого гена. Процент — это показатель разброса признаков, а не число видов или мера сознания. При вымирании средние и разнообразие равны нулю.

История снимается раз в 10 шагов (1 секунду), хранится до 600 точек. Гистограммы генов имеют 20 интервалов. Цвет организма меняется от бирюзового до фиолетового с агрессивностью. Накопленные рождения и смерти отображаются внизу.

## Архитектура и производительность

- `src/engine.ts` — чистое вычислительное ядро, параметры, статистика, сериализация, валидация и повтор.
- `src/worker.ts` и `src/session.ts` — владелец двух независимых миров, команды и атомарное восстановление сессии.
- `src/render.ts` — Canvas 2D, не меняет вычислительное состояние.
- `src/main.tsx` — React UI, Canvas-инспектор, графики SVG, гистограммы, управление и файлы.
- `src/engine.test.ts`, `src/session.cases.ts` — детерминизм, снапшоты, повтор, Worker, питание, наследование, мутации, смерть и границы.

Ядро всегда работает в Web Worker. Пространственные корзины ограничивают поиск соседей; питание считывается только в локальном радиусе. Один пакет ограничен 25 шагами; новый не отправляется до ответа Worker. На 600 организмов проверка 100 шагов занимает порядка 0,8–1,3 с в текущем окружении разработки; это не измерение на MacBook. Реальная скорость зависит от устройства и параметров. При 10× или сравнении двух густонаселённых миров скорость может быть ниже выбранной, но шаги не пропускаются. На главный поток передаются копии миров; для значительно больших популяций потребуются упакованные буферы и более редкая передача статистики.

Долгий повтор эксперимента занимает Worker; UI остаётся отзывчивым. Журнал действий хранится целиком, графическая история ограничена. Снапшоты скачиваются пользователем и не отправляются по сети. Отдельного сервера, облачного хранения или платных сервисов нет.
